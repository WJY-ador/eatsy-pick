# Threads 홍보 글 말투

eatsy-pick 홍보는 Threads 위주로 간다(2026-11-25 사용자 결정, 블로그는 우선순위에서 뺌). 목표는 체험단 글이 아니라 동네 사람이 한 줄 남긴 글처럼 읽히는 것이다. 블로그 글쓰기 규칙은 `scripts/blog-guide.md`가 따로 갖는다.

## 근거와 한계

2026-11-25 조사. Threads 유효 39편(개인 후기 13, 질문 9, 가게와 큐레이션 14, 사장 3), 비교용 네이버 블로그 30편.
- Threads 검색은 로그인 없이 막혀 검색엔진에 잡힌 글만 모았다. 가게 계정 글이 많이 섞였고, 긴 글은 약 500자에서 잘렸다.
- 개인 후기 표본이 13편이라 비율은 방향 참고용이다.

| 항목 | Threads 개인 후기 | 네이버 블로그(대조) |
|---|---|---|
| 길이 | 1~4줄, 중앙값 약 66자 | 평균 2,200자 |
| 문장 끝 | ~다 58%, ~음, ~함 17%, 반말 17%, ~요 0% | ~요 59%, ~니다 22% |
| 말줄임표 | 44% | 46% |
| ㅎㅎ | 11% | 60% |
| 느낌표 | 33% | 93% |
| 인사로 시작 | 0% | 60% |
| 가격 숫자 | 7% | 83% |

## 기본 말투

- 음슴체와 짧은 평서를 섞는다: ~함, ~임, ~음, ~더라, ~네, ~었다. 한 글 안에서 ~요와 ~니다는 쓰지 않는다.
- 문장은 짧게 끊고 끝을 다 맺지 않아도 된다. 명사로 끝나는 조각("냉동삼겹살 맛집임..")이 자연스럽다.
- 길이는 1~4줄, 길어도 한 화면. 소제목, 번호 목록, 굵은 글씨는 쓰지 않는다.
- 첫 줄은 상황이나 한 줄 평으로 연다. 인사, 자기소개, "소개해 드릴게요"로 열지 않는다.
- 마무리는 한 줄로 툭 끝낸다. 요약, 감사 인사, "도움이 되셨길" 같은 맺음은 없다.

## 감정 표현

- 말줄임표: 개인 후기에서 가장 흔하다. 문장 끝에 `..`나 `...`를 한 번. 감탄을 길게 끌 때 `..........`처럼 늘이기도 한다. 쉼표 두 개 `,,`도 같은 자리에 쓴다.
- ㅎㅎ: 한 글에 한 번, 머쓱하거나 가볍게 넘길 때.
- ㅋㅋㅋ: 웃긴 장면이 있을 때만 여러 개 이어서. 맛 평가에는 붙이지 않는다.
- ㅠㅠ, ㅜㅜ: 아쉬움(웨이팅, 품절, 멀다)에 한 번.
- 물결(~): 권유나 가벼운 끝맺음에 한 번("여기도 괜찮네~").
- 느낌표: 글 전체에 한두 개까지.
- 이모지: 0~2개, 문장 끝에. 줄머리에 📍 ⏰ 같은 정보 불릿은 쓰지 않는다(가게와 큐레이션 계정 티가 난다).

## 신조어와 구어

관찰한 표현. 한 글에 한두 개만 섞는다. 여러 개를 몰아 쓰면 오히려 가게 홍보 계정처럼 읽힌다.

| 표현 | 쓰임 |
|---|---|
| 존맛, 존마탱 | 맛 평가 한 단어 |
| 찐맛집, 찐 | 진짜라는 강조. 가게 홍보 글에도 많아서 한 번만 |
| 겉바속촉 | 튀김, 구이 식감 |

| 그잡채 | 그 자체 |
| 미쳤음, 미쳤다 | 맛이 아주 좋음 |
| 맛도리 | 맛있는 것 |
| 밥도둑 | 반찬, 국물 |

## eatsy-pick 정보 넣는 법

- 숫자는 하나만, 문장 안에 녹인다. 예: 결제 데이터로 보니 이 동네 점심 대표 피크가 금요일 점심인 집이 60곳이더라.
- 지명은 동네 이름 하나. 주소, 영업시간, 전화는 쓰지 않고 링크로 보낸다(링크는 첫 댓글이나 끝 줄).
- 아쉬운 점이나 조건 한 줄을 넣는다(저녁엔 웨이팅 있음, 주차 애매함).
- 데이터 문장은 기준을 먼저 쓴다(결제 건수 기준, 최근 1개월). 손님 수, 비율로 바꿔 말하지 않는다.

## 피할 것

체험단 글은 한 단어보다 조합에서 티가 난다. 아래가 한 글에 겹치면 광고로 읽힌다.
- 서비스어: 소개해 드릴게요, ~랍니다, ~드려요, 꼭 가보세요
- 상투어: 인생 맛집, 강력 추천, 무조건, 숨은 보석, 가성비 최고
- 나열: 가성비, 푸짐, 넉넉, 든든을 이어 쓰기
- 선언: 내돈내산 솔직 후기
- AI 티: 또한, 따라서, 결론적으로, 다양한, 조화로운, 완벽한, 매력적인, ~할 수 있습니다, 3개 항목 나열, 소제목 정리
- 해시태그 덩어리. 쓰더라도 0~2개, 맨 끝.

## 열린 질문

- 열린 질문: 어느 계정으로 올리나. 개인 계정이면 이 문서 그대로, 서비스 공식 계정이면 해요체로 바꿔야 한다.
- 열린 질문: Threads 표본을 늘릴지. 로그인한 Threads 검색 화면에서 좋아요 상위 개인 후기를 더 모으면 비율이 단단해진다. 로그인 사용은 사용자 승인이 필요하다.
- 열린 질문: 이 규칙으로 시험 글을 써서 사람 글과 같은 지표(문장 끝, 말줄임, 길이)로 재 볼지.
